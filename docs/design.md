# デザイン仕様

画面の見た目のルール（色・文字・形・文言・動き）。画面に触る作業では、ここに書かれた物だけを使う。

## 考え

**この画面は「真夜中の寝室を、音の文字だけで描いたマンガの1コマ」に見える。**

- 主役は擬音の文字（「ジリリリ」「ワンワン」）。絵は寝ている人とふとんだけで、部屋の物は描かない
- うるさい時と静かな時の差を、画面全体でいちばん大きく見せる。鳴っている文字は震え・効果線・波を出し、背景が赤く濁る。止めると文字が押しつぶれて「・・・」になり、全部止めると「シーン」
- 止める音は「とがって」、押しちゃダメな音は「やわらかく」見せる（面を敷くのは押しちゃダメな音だけ）

## 参考にした実例（`factory-refs/board.md` に詳しく）

- SCRAMBLE LABEL https://scramblelabel.jp/ — 黒地に白い巨大な文字がずれて重なる＝音の震え。→ 鳴っている文字の上下にずれた写し。結果の斜めの帯
- blkswn https://blkswn.tokyo/ — 字間を空けた細い日本語と罫だけの静かな面。→ 時計まわりの小さな文字、結果の数字の上の罫
- Chrome Music Lab https://musiclab.chromeexperiments.com/ — 音ごとに1色。→ 音の種類ごとに1色
- itch.io の typography タグ（Glyph Loops など）— 黒地に極太の文字1つで絵になる。→ タイトルは文字だけ
- 反面教師：itch の「Shhh...」「Sleeping Through the Air Raid Sirens」— 何が鳴っているか遠目に分からない、キャラ移動が遅い

## 構図とグリッド

- 舞台は縦長の箱：幅 = min(画面の幅, 画面の高さ×0.6)、真ん中に置く。スマホでは画面いっぱい。PC では両脇が外の色で、左に「MUTE THE ROOM」を縦に大きく（白の 7%）、右に「HOW TO」と操作の説明
- 舞台の中：上 0〜100px が時計とねむり、118px から寝ている人の上（画面の高さ×0.79）までが音の出る場所、その下が寝ている人
- 左右の余白 18〜22px。音の文字は舞台からはみ出さないよう横を寄せる
- ボタンは寝ている人の上（下から「画面の高さ−寝ている人の上端＋14px」）。低い画面では結果の数字の下に収める

## 部品

- **止める音**：擬音を夜の色（太さ＝文字の 20%）でふちどり、その音の色で塗る。上下にずれた写しを細い線で2つ（震え）。まわりに効果線 8〜18 本（14 コマ/秒で入れ替わる）と、楕円の波が2つ外へ広がる。面は敷かない
- **押さえている時**：文字が横 +18%・縦 −45% までつぶれ、色が白へ抜ける。楕円の輪（白 18% の地に白い弧）が満ちる。指の所に白 55% の輪（半径 22px）
- **押しちゃダメな音**：月の色。点線の楕円がゆっくり回り、月の色 9% の面を敷く。下に「子守唄｜押さないで」（14px・700）
- **止めた時**：文字が平たくつぶれて消え、「・・・」が浮く。色の短い線が12本はじける。「+150」が白で浮く
- **押しちゃダメを押した時**：赤い×と「ダメ！」、画面が赤く光り大きく揺れる
- **ねむりのゲージ**：「ねむり」の右に高さ 8px・角丸 4px。月の色、30% 未満で赤く点滅
- **夜の進み**：舞台のいちばん上に 3px の月の色の線
- **寝ている人**：線だけの丸い顔（線 2.6px）、まくら、波打つふとん（斜線の模様）。眠り＝下向きの弧の目と小さく動く口、ねむり 35% 未満＝まっすぐの目と眉、起きた＝丸い目と怒った眉と赤い「！」、守りきった＝笑った目
- **主ボタン**：黄の地・夜の文字・高さ 56px・角丸いっぱい・黄の光。**副ボタン**：夜の地・白の 2px の線。押すと 0.96 倍。フォーカスは黄 3px の輪（3px 離す）
- **音を消すボタン**：右上 44px の丸、白 35% の線。スピーカーの絵（消した時は×）
- **お題の副ボタン**：副ボタンの部品そのまま（夜の地・白の 2px の線・高さ 56px）。タイトルで主ボタンの 12px 上に同じ幅で置く。文字は「今夜のお題 11/3」（日付は日本時間の今日）。遊び方の2行は、ボタンが増えた分（68px）だけ上へ上げる
- **結果の1枚**：上に「MUTE THE ROOM」と「今夜の記録」、大きな時刻（守りきった＝夜明け、起きた＝赤、寝坊＝橙）と一言。−6° 傾いた白い帯に「称号」と「「称号名」」、帯の上下の縁に止める音の7色が 18px ずつ並ぶ。「今夜のうるささ」は 64 本の棒の波形（月→橙→赤）、23:00 と 7:00 を下に、起きた所に赤い縦線。数字3つ（黙らせた音・シーン・押しちゃった）は上に細い罫
- **共有する画像**：結果の1枚（上の部品）と背景・寝ている人を、390×700 論理px の 2 倍＝780×1400 の PNG にする。画面の大きさによらず同じ構図で、アニメーションを終えた状態。ボタン・音を消すボタン・トースト・PC の両脇の文字・URL は入れない（URL は共有する文に入れる）。色・文字・文言は結果の1枚と同じ。ファイル名は `mute-the-room.png`

## 文言

- タイトル：「鳴ったら、／押さえろ。」「23:00 から 7:00 まで、寝かせておけ。」「うるさい音は、指で押さえ続けて止める」「青白い音（子守唄・寝息・雨）は押しちゃダメ」、ボタン「夜をはじめる」「今夜のお題 11/3」（日付は日本時間の今日）
- 遊ぶ時：「黙らせた n」「ねむり」「シーン」「ダメ！」「朝だ。これは止めないで」「7:00 の目覚まし｜押さないで」
- 結果：お題で遊んだ回だけ、一言の下に薄字（14px・700・字間 0.1em）で「今夜のお題 11/3」（共有文にも同じ1行）。「まで守りきった」「に起きちゃった」「の目覚ましを止めて寝坊させた」、ボタン「もう一度」「結果を共有」、コピー時「結果をコピーしました」、画像を保存した時「画像を保存しました」
- 称号：夜の番人／静寂の職人／ぎりぎりの子守り／二度寝製造機／うるさい部屋の住人／うたた寝の見張り／夜ふかしの守り手／朝まであと一歩

## 動き

- 鳴っている文字の震えは大きさに比例（最大 3.2px）。画面全体もうるささに比例して揺れる（最大 4px）
- 押さえ始め：小さな揺れ 2px。止めた時：揺れ 5px。罰：揺れ 16px と赤い光。起きた時：揺れ 20px
- 結果は、時刻 → 帯（左から滑り込む）→ 波形と数字、の順に 0.25 秒ずつずらして出す（ease-out 3 乗）
- `prefers-reduced-motion` では、揺れ・震え・写し・効果線の入れ替わり・はじけ・帯の滑り込みを止める（色と形の変化だけ残す）

## 音（Web Audio で作る）

- 種類ごとに音が鳴り、左右の位置で振り分ける。押さえている間はこもる（ローパス 380Hz）。止めた時は「ぽすっ」と沈む音、全部止めた時は高く小さな鈴
- 最初のタップ・キーで鳴らし始める。右上のボタンか M キーで消せる

## 写真

使わない。絵は全部 Canvas の線と文字で描く。
