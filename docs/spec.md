# 仕様書

アプリの「何を・どう動かすか」を書く。AIは作業の前に必ずここを読む。

## 目的

スマホの縦画面で遊べるWebゲーム。短い指示や効果音の中から、鳴ってはいけない音だけを指で押さえて静かにさせる、新しい遊び方で結果を共有できる。（元のメモ：見たことない遊び方で、思わず人に送りたくなる Web ゲーム（ジャンルはおまかせ））

## 前提

- 使う人・使う場面（デザイン担当の分析。推定を含む）：
  - 使う人：X や TikTok で流れてきた動画・結果画像を見て、スマホでリンクを開いた人（説明を読まずに遊び始める）
  - 使う場面：電車や寝る前に縦持ちで1回 30〜70 秒、親指1〜2本で遊ぶ。負けたらすぐもう一度
  - 結果：「◯:◯◯ に起きちゃった」と称号の1枚をスクショするか、共有ボタンで友だちに送って張り合う
  - PC では、マウスか、音の横に出るキー（A S D F J K L）を押さえて遊ぶ
- 技術：TypeScript・Vite（Canvas／WebGL）、テストはVitest。Vercel で公開する（スマホ・PC のブラウザで遊ぶ）
