# mute-the-room

スマホの縦画面で遊べるWebゲーム。短い指示や効果音の中から、鳴ってはいけない音だけを指で押さえて静かにさせる、新しい遊び方で結果を共有できる。

- 仕様：[docs/spec.md](docs/spec.md)
- 見た目：[docs/design.md](docs/design.md)

[ai-dev-template](https://github.com/Gaku1205/ai-dev-template) の工場で、1行のメモ（見たことない遊び方で、思わず人に送りたくなる Web ゲーム（ジャンルはおまかせ））から作ったサービスです。Issue を書くと、AI が清書・実装・レビュー・マージまで進めます（[docs/pipeline.md](docs/pipeline.md)）。
